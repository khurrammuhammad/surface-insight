# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short:

- Be respectful and assume good faith. Disagree with ideas, not people.
- No harassment, discrimination, personal attacks, or publishing other people's private information.
- Keep issues and pull requests on topic and constructive.

Maintainers may edit or remove comments, close issues, and block users that break these rules. To report a problem, use **Security tab > Report a vulnerability** on this repository (it is private to the maintainer), or contact the maintainer through their GitHub profile.
